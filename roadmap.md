# Roadmap

## What this is
A study task list for people learning Tagalog who want to see which language skills they are neglecting. Each task is tagged with one skill, and the site shows which skill you have practiced least.

## What Done means
A Tagalog learner who has never seen the site opens the live address, creates an account with an email and password, and logs in. They add study tasks, each tagged with one of six skills (Listening, Speaking, Reading, Writing, Vocabulary, Grammar), and tick tasks off when finished. A skill balance panel shows how many tasks they have completed in each skill and names the one they have practiced least. When they log out and return later, their tasks are still there, and no other account can see them.

## Slices
1. Sign up and log in | done-criteria: (a) Sign up on the live site with a new fake email such as test1@example.com and a password; you land on a page showing "Signed in as test1@example.com". (b) Click Log out, then type the tasks page address directly; you see the login form, not the tasks page. (c) Log in with the right email and a wrong password; an error message appears and you stay on the login form. (d) Close the tab, reopen the site, log in with the right password; "Signed in as test1@example.com" appears again. | status: ACTIVE
2. Tagged tasks that stay put | done-criteria: (a) Signed in, type "Listen to a 10-minute Tagalog podcast", choose Listening, click Add; the task appears in the list with a "Listening" label. (b) Refresh the page, then log out and back in; the task is still there with its label. (c) Tick a task as done and refresh; it still shows as done. (d) Log in as a second account; none of the first account's tasks are visible. | status: pending
3. Skill balance panel | done-criteria: (a) With completed tasks in only some skills, the panel lists all six skills with a number beside each, unused skills showing 0. (b) The skill with the fewest completed tasks is labeled "Least practiced"; if several are tied, each tied skill has the label. (c) Note the Speaking number, tick a Speaking task done, refresh; the Speaking number is one higher. (d) A brand-new account shows 0 for all six skills and the message "No completed tasks yet". | status: pending
